# Dotfiles

Welcome to my dotfiles repository. My themes are mainly focussed on the Gruvbox
color palette.

This is a NixOS flake: system configuration, [Hyprland](https://hyprland.org),
and all user-level dotfiles are managed together through NixOS + home-manager.

## Setting up a new machine

1. Install NixOS with the standard installer. This generates
   `/etc/nixos/hardware-configuration.nix`, which the flake picks up
   automatically. Boot into the fresh system and get online (`nmtui` for wifi).

2. Clone this repo (anonymous HTTPS needs no credentials; or copy your SSH
   keys over first and clone via SSH):

   ```shell
   nix-shell -p git --run "git clone https://github.com/tluijken/.dotfiles ~/.dotfiles"
   ```

3. Create `/etc/nixos/local.nix` for machine-specific settings (see below).

4. First rebuild — flakes aren't enabled yet on a fresh install, so enable
   them inline this one time:

   ```shell
   sudo NIX_CONFIG="experimental-features = nix-command flakes" \
     nixos-rebuild switch --flake ~/.dotfiles#nixos --impure
   ```

5. Copy your SSH keys over (keychain expects `~/.ssh/github`) and flip the
   remote to SSH:

   ```shell
   git -C ~/.dotfiles remote set-url origin git@github.com:tluijken/.dotfiles.git
   ```

After that, rebuilds are just `update` (or `upgrade` to also bump inputs) —
zsh aliases for `nh os switch`.

## Machine-specific configuration

The flake contains no machine-specific hardware configuration. It imports
`/etc/nixos/hardware-configuration.nix` (generated by `nixos-generate-config`
during installation) and, if present, `/etc/nixos/local.nix` for other
machine-specific settings: `system.stateVersion`, extra LUKS devices, and
hardware-dependent modules such as NVIDIA. Example:

```nix
# /etc/nixos/local.nix
{ ... }:

{
  # Only on machines with an NVIDIA GPU:
  imports = [ /home/thomas/.dotfiles/nixos/nvidia.nix ];

  hardware.nvidia.prime = {
    intelBusId  = "PCI:0:2:0";
    nvidiaBusId = "PCI:1:0:0";
    sync.enable = true;
  };

  # Extra LUKS devices not covered by hardware-configuration.nix:
  boot.initrd.luks.devices."luks-<uuid>".device = "/dev/disk/by-uuid/<uuid>";

  # The NixOS release this machine was first installed with:
  system.stateVersion = "24.05";
}
```

Because those files live outside the repo, rebuilds need the `--impure` flag
(the `update`/`upgrade` aliases already pass it):

```shell
sudo nixos-rebuild switch --flake ~/.dotfiles#nixos --impure
```
